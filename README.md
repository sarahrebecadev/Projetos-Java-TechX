# ☕ Projetos Java — TechX

> Repositório de estudos e entregas práticas de Java, organizado por sprints da Trilha Backend.

Este espaço reúne atividades desenvolvidas durante a aprendizagem da linguagem Java, começando pelos primeiros comandos e avançando para conceitos de Programação Orientada a Objetos (POO), construção de classes, criação de objetos e aplicação de regras de negócio.

## 📚 Sobre o repositório

O objetivo é manter os projetos organizados em um único lugar, facilitando a consulta, o acompanhamento da evolução técnica e a apresentação das atividades realizadas.

## 🗂️ Organização dos projetos

| Sprint | Projeto | O que foi desenvolvido |
|---|---|---|
| **Sprint 1** | Hello World | Primeiro programa em Java, com criação da classe principal e impressão de uma mensagem no console. |
| **Sprint 2** | Programação Orientada a Objetos | Exercícios com as classes `Pessoa` e `Carro`, criação de objetos, atribuição e alteração de atributos e comparação de valores usando estruturas condicionais. |
| **Sprint 3** | Sistema de Controle de Elevador | Simulação de um elevador com controle de andar e peso, aplicando classes, atributos, métodos, construtor, encapsulamento e validações. |
| **Sprint 4** | Sistema de Pagamentos | Implementação de um sistema que representa pagamentos por Pix, débito e crédito, aplicando abstração, herança, encapsulamento e polimorfismo. |

## 🧠 Principais conhecimentos praticados

- Sintaxe básica e estrutura de um programa Java;
- Classes, objetos e atributos;
- Métodos e construtores;
- Estruturas condicionais;
- Encapsulamento;
- Herança e abstração;
- Polimorfismo e sobrescrita de métodos;
- Organização de código em diferentes arquivos e classes;
- Implementação de regras e validações de negócio.

## 🛠️ Tecnologias e ferramentas

- **Java** — linguagem utilizada nos exercícios;
- **IDE ou editor de código** — por exemplo, IntelliJ IDEA, Eclipse ou Visual Studio Code;
- **Git e GitHub** — versionamento e organização dos projetos.

## ▶️ Como executar

1. Tenha o JDK (Java Development Kit) instalado.
2. Clone ou baixe este repositório.
3. Acesse a pasta da sprint desejada.
4. Abra os arquivos em uma IDE Java ou compile pelo terminal.
5. Execute a classe que contém o método `main`.

Exemplo para compilar e executar um arquivo simples:

```bash
javac HelloWorld.java
java HelloWorld
```

> **Observação:** cada sprint é um exercício independente. Para executar, entre na pasta correspondente e siga as instruções específicas do projeto, quando houver.
